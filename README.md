## 적용 방법
각 폴더 별 `README.txt` 확인

### Windows
```bash
1. ZIP 파일을 압축 해제
2. YuhiKaerimichiKoreanPatch.exe를 더블클릭
3. SmartScreen이 뜨면 [추가 정보] → [실행]이 필요할 수 있음
4. 원본 게임을 자동 다운로드 및 패치한 뒤 브라우저가 열림
5. 종료는 콘솔에서 Ctrl+C
```

### macOS
```bash
1. ZIP 파일을 압축 해제
2. 실행.command를 더블클릭
3. 차단되면 YuhiKaerimichi.command [우클릭] → [열기]
3-1. 차단되면 [설정] → [개인정보 보호 및 보안] → 맨 아래로 내려서 허용하기
3-2. YuhiKaerimichiKoreanPatch에 대한 허용이 한 번 더 필요할 수도 있음
4. 원본 게임을 자동 다운로드 및 패치한 뒤 브라우저가 열림
5. 종료는 터미널에서 Ctrl+C
```
